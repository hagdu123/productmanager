Product Manager — MERN Stack CRUD Application
Tech Stack: React.js, Node.js, Express.js, MongoDB Atlas, Axios, Render

Developed a full-stack CRUD application for managing products.
Built RESTful APIs using Express.js and integrated MongoDB Atlas for database operations.
Implemented React frontend with Axios for API communication.
Deployed application using Render.
